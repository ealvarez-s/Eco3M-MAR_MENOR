Como instalar:
OPCION 1> Non-interactive (silent) installation, which allows you to define the installation configuration only once and does not require any user input during installation:
Como root:
sudo sh ./l_[Toolkit Name]Kit_[version].sh -a --silent --eula accept
Como user:
sh ./l_[Toolkit Name]Kit_[version].sh -a --silent --eula accept

OPCION 2> Interactive mode, which prompts you to select or confirm certain options during the installation process:
Como root:
sudo sh ./l_[Toolkit Name]Kit_[version].sh -a --cli
Como user:
sh ./l_[Toolkit Name]Kit_[version].sh -a --cli


YO HE USADO:
sh ./l_BaseKit_p_2024.2.1.100_offline.sh -a --silent --eula accept
sh ./l_HPCKit_p_2024.2.1.79_offline.sh -a --silent --eula accept

Como user, queda instalado en:
~/intel/oneapi

Set up environment to use Intel compilers:
export PATH=~/intel/oneapi/mpi/latest/bin:$PATH
export LD_LIBRARY_PATH=~/intel/oneapi/mpi/latest/lib:$LD_LIBRARY_PATH
source ~/intel/oneapi/setvars.sh

Si se necesita re-exportar las variables:
source ~/intel/oneapi/setvars.sh --force

Check:
mpirun --version
mpiifort --version
